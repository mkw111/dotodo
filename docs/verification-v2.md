## 테스트가 확인하는 동작

- 월말·윤년·평일 반복, 연도 경계 날짜, 31일 반복의 월말 보정
- 반복 완료 시 다음 항목 생성, 완료 취소 후 재완료 시 중복 생성 방지
- 오늘의 지난 기한 포함, 다음 7일 경계, 휴지통 제외
- 한국어 날짜·태그·우선순위 빠른 입력
- 습관 목표와 연속 달성, 실제 종료 시각 기반 타이머 경과
- 이전 할 일 데이터 보존 이관, 잘못된 백업·중복 ID·없는 리스트 참조 거절
- 서버 저장, 오래된 revision의 409, 잘못된 입력 거절과 기존 데이터 보존, 이전 TODO 최초 이관

## 브라우저에서 직접 확인한 흐름

1. 기존 0.1 데모 할 일이 새 화면에 유지됨.
2. `오늘 dotodo 기능 정리 #프로젝트 !1` 입력 후 날짜·태그·우선순위 반영.
3. 상세 메모와 체크리스트 추가·저장, 행의 체크리스트 개수 반영.
4. 작업의 집중 화면 이동, 타이머 시작·새로고침·남은 시간 경과·일시정지.
5. 습관 생성과 오늘 체크, 달성 횟수·연속 기록 반영.
6. 월 캘린더의 일정과 선택 날짜 목록 표시.
7. API 모드 목록 조회와 수정의 실제 서버 반영.

검증용 API 실행은 메모리 DB를 사용했으며 사용자 파일 DB를 덮어쓰지 않았습니다. 브라우저 데모에는 확인용 할 일 1개와 습관 1개를 추가했습니다.

## 확인하지 않은 범위

Android/iOS 실기기 실행, APK·IPA 네이티브 빌드·서명, 백그라운드 알림, 브라우저 알림 권한 승인과 실제 알림 수신, 모든 화면 크기의 시각 검사, 터치 드래그, 외부 서비스 연동은 검증하지 않았습니다. Expo 번들 성공은 네이티브 설치 성공을 뜻하지 않습니다.

다중 기기 실시간 동기화·협업·인증과 운영 DB 배포는 구현 범위 밖입니다. 전체 기능 및 제한은 [TickTick 분석 문서](ticktick-analysis.md)를 참고하세요.

# dotodo 0.3 · 스마트 입력, 개인 랭크, 시간표

## 시중 앱에서 참고한 점

- Todoist / Microsoft To Do: 입력 중 날짜·반복·시간을 인식하고, 인식을 취소해 일반 텍스트로 남기는 흐름
- TickTick: 할 일·캘린더·집중·습관을 한 작업 흐름으로 연결
- Habitica: 실제 행동의 완료에 보상을 연결

이를 바탕으로 dotodo에는 취소 가능한 인라인 칩, 날짜 빠른 버튼, 개인 랭크, 일일 퀘스트, 연속 활동, 업적, 주간 XP 차트를 추가했습니다. 다른 앱의 계정이나 데이터를 연결하는 기능은 아닙니다.

공식 참고: [Todoist 날짜 입력](https://www.todoist.com/help/todoist/features/schedule-a-date-and-time-for-your-todoist-tasks-q7VobO), [Microsoft To Do 스마트 인식](https://support.microsoft.com/en-us/todo/smart-due-date-reminder-recognition-in-microsoft-to-do), [TickTick 기능](https://www.ticktick.com/features), [Habitica 기능](https://habitica.com/static/features).

## 입력 예시

| 입력 | 반영되는 내용 |
| --- | --- |
| `오늘 운동` | 오늘 날짜 / 제목 `운동` |
| `내일 오후 3시 회의` | 내일 15:00 / 제목 `회의` |
| `매일 독서` | 오늘부터 매일 반복 |
| `매주 수요일 운동` | 오늘 포함 다음 수요일부터 매주 반복 |
| `수요일 운동` | 오늘 포함 다음 수요일, 반복 없음 |
| `이번 주 보고서` | 이번 주 일요일 마감 |
| `다음 주 준비` | 다음 주 월요일 마감 |
| `다음 주 수요일 미팅` | 다음 주 수요일 |
| `평일마다 산책` | 다음 평일부터 평일 반복 |
| `매월 정산` | 오늘부터 매월 반복 |
| `2026-11-10 15:30 미팅 #업무 !1` | 날짜·시간·태그·높은 우선순위 |

`모레`, `글피`, `오전 9시`, `오후 3시 30분`도 인식합니다. `오늘의 기록`, `수요일엔 운동`처럼 일반 단어에 붙은 표현과 잘못된 날짜/시간은 그대로 둡니다. 모든 자연어를 해석하는 AI는 아니며 위 패턴을 지원합니다.

### 칩 인식 취소

`오늘 운동`을 입력하면 `[오늘] 운동`으로 강조됩니다. **`[오늘]`을 누르면 단어를 삭제하지 않고 일반 텍스트 `오늘 운동`으로 전환**합니다. 해당 인식을 취소한 뒤 다른 글자를 입력해도 취소를 유지합니다. 단어를 지우고 다시 입력하거나 `다시 인식`을 누르면 다시 인식합니다.

취소된 날짜 표현은 오늘 보기의 기본 날짜도 자동 적용하지 않습니다. 직접 날짜 선택기를 사용하면 날짜를 지정할 수 있습니다. 시간만 있고 날짜가 취소된 경우 날짜 지정 전에는 시간 설정을 저장하지 않습니다.

빠른 추가와 새 할 일 상세 입력에서 같은 인식기를 사용합니다. 기존 할 일 제목을 수정할 때는 이미 지정한 날짜가 뜻밖에 바뀌지 않도록 일반 제목 편집을 유지합니다. 한글 조합 중에는 DOM 강조를 지연하고 조합 완료 후 칩을 만듭니다.

## 개인 랭크

사이드바 아래 티어 카드를 누르면 랭크 화면이 열립니다. 기존 완료한 할 일·습관·집중 기록도 반영합니다.

| 티어 | 시작 XP |
| --- | ---: |
| 아이언 | 0 |
| 브론즈 | 200 |
| 실버 | 600 |
| 골드 | 1,200 |
| 플래티넘 | 2,200 |
| 에메랄드 | 3,600 |
| 다이아몬드 | 5,400 |
| 마스터 | 8,000 |
| 그랜드마스터 | 11,000 |
| 챌린저 | 15,000 |

아이언~다이아몬드는 IV → III → II → I 디비전을 가지며, 각 구간의 진행률을 LP로 표시합니다. 마스터부터는 디비전 없이 다음 티어 진행률을 표시합니다. XP 기준과 배지는 dotodo 자체 규칙·벡터로 만들었으며 League 계정이나 공식 순위와 연결되지 않습니다.

### 경험치

- 할 일 완료: +20 XP
- 하루 습관 목표 달성: 습관·날짜별 +10 XP
- 집중 세션 완료: 5분당 +3 XP, 세션당 최대 60 XP, 짧은 세션 최소 1 XP
- 일일 퀘스트: 같은 날 할 일 3개 + 습관 1개 + 집중 1회 모두 완료하면 +30 XP

완료 취소 시 관련 보상을 비활성화하고, 다시 완료해도 동일한 원본 ID의 보상 하나만 갱신합니다. 퀘스트 조건이 깨지면 퀘스트 보상도 회수합니다. 완료 기록을 휴지통으로 옮기거나 영구 삭제한 경우 이미 달성한 XP는 남깁니다. 보상 기록은 `rewards`에 저장하며 백업·서버 저장에 포함됩니다.

이 티어는 개인 성장 기록입니다. 실시간 경쟁 순위·온라인 랭킹·서버 권위의 부정행위 검증은 구현하지 않았습니다.

## 일간·주간 시간표

캘린더의 **일 / 주**를 선택하면 00:00~24:00 시간표가 열립니다.

- 일정 본문을 위아래로 드래그: 15분 단위 시작 시간 변경
- 주간 보기에서 옆 날짜 열로 드래그: 날짜와 시간 변경
- 아래쪽 손잡이를 드래그: 15분 단위 길이 조정
- 빈 시간대 클릭: 해당 날짜·시간이 들어간 새 할 일 작성
- 종일 일정을 시간표로 드래그: 시간 지정
- 겹치는 일정: 별도 열로 배치
- 일정 선택: 상세 편집. 소요 시간은 상세에서도 변경 가능
- 키보드: 일정에서 Alt+위/아래는 15분 이동, Alt+좌/우는 날짜 이동. 길이 손잡이에서 위/아래는 15분 길이 조정

기존 시간 있는 할 일의 기본 길이는 30분이며 `durationMinutes`로 저장합니다. 길이는 15~720분입니다. 드래그는 당일 범위 안에서 제한하며, 여러 날에 걸친 연속 시간 블록은 지원하지 않습니다. Google Calendar 계정 연동은 포함하지 않습니다.

## 검증

- 프론트 TypeScript와 Vite 프로덕션 빌드 통과
- 프론트 로직 18개, 백엔드 통합 6개 통과
- 브라우저에서 칩 인식 → 인식 취소 → 다시 인식 → 15:00 일정 저장 확인
- 브라우저에서 해당 일정을 15:00 → 14:00으로 드래그 후 저장 확인
- 아래 손잡이로 30분 → 60분 변경 확인
- 할 일 완료 시 70 → 90 XP, 취소 시 90 → 70 XP 확인

시간 격자·겹침·경계·티어·중복 보상·데이터 형식은 자동 테스트에 포함했습니다. Android/iOS 실기기 터치 드래그와 실제 한국어 IME 조합은 실기기에서 검증하지 않았습니다. 기존 모바일 셸은 같은 웹 화면을 사용합니다.

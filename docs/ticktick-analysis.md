# TickTick 분석과 dotodo 0.2 구현 범위

2026-10-28에 공개된 공식 기능 소개와 도움말을 확인했습니다. TickTick의 비공개 코드나 유료 계정 내부에 접근한 분석은 아닙니다.

## 참고한 흐름

TickTick은 빠른 할 일 입력, 날짜 조건의 스마트 목록, 사용자 리스트와 상세 편집을 중심으로 캘린더·집중·습관 도구를 연결합니다. dotodo도 같은 할 일을 여러 관점에서 정리할 수 있도록 구성했습니다. 브랜드·문구·아이콘·구현 코드는 dotodo용으로 만들었습니다.

| 공식 자료에서 확인한 기능 | dotodo에 구현한 동작 |
| --- | --- |
| 스마트 목록 / 사용자 리스트 | 수집함, 오늘(지난 기한 포함), 내일, 다음 7일, 전체, 중요, 완료, 사용자 리스트 추가·이름·색상 수정 |
| 빠른 입력 / 날짜 인식 | `오늘`, `내일`, `모레`, `YYYY-MM-DD`, `#태그`, `!1~!3` 인식. 모든 자연어를 해석하는 NLP는 아님 |
| 작업 상세 | 메모, 마감 날짜·시간, 4단계 우선순위, 태그, 체크리스트, 리스트 이동 |
| 반복 일정 | 매일 / 평일 / 매주 / 매월. 완료 시 다음 항목을 한 번 생성. 기존 완료를 취소해도 생성된 다음 항목은 유지 |
| 목록 / 칸반 | 정렬, 날짜·우선순위·리스트 그룹, 우선순위별 칸반, 끌어서 우선순위 변경 |
| 캘린더 | 월·주·일, 기간 이동, 선택 날짜 일정, 날짜별 추가, 끌어서 날짜 이동. 종일·시간 표시는 있지만 시간대별 격자 타임블로킹은 아님 |
| 아이젠하워 매트릭스 | 중요(높은 우선순위) × 긴급(오늘까지의 날짜) 4분면, 끌어서 분면 변경 |
| 집중 | 집중 / 휴식 시간 설정, 시작·일시정지·초기화, 작업 선택, 완료 기록·오늘 합계 |
| 습관 | 사용자 습관, 아이콘·색상·하루 목표, 날짜별 횟수, 주간 체크, 연속 달성, 28일 히트맵 |
| 기본 사용 환경 | 전체 검색, 다중 선택 완료·내일로·휴지통, 실행 취소·복원·영구 삭제, 라이트·다크·시스템 테마, 포인트 색상, 주 시작 설정 |
| 데이터 | 로컬 저장 또는 서버 저장, JSON 백업·검증·복원, 예전 데이터 이관, 수정 충돌 감지 |

## 화면 구성

- 기능 아이콘 레일: 할 일 / 캘린더 / 매트릭스 / 집중 / 습관 / 설정
- 사이드바: 스마트 목록 / 내 리스트 / 태그 / 완료 / 휴지통
- 작업 영역: 빠른 입력, 목록·칸반, 정렬·그룹·다중 선택
- 상세 패널: 메모·날짜·시간·우선순위·반복·체크리스트·태그 편집, 저장 버튼
- 넓은 화면: 작업 미선택 시 오늘의 캘린더·습관·집중 요약
- 좁은 화면: 하단 기능 메뉴, 접이식 사이드바, 전체 화면 상세

## 저장과 동기화

새 API는 `GET /api/workspace`, `PUT /api/workspace`입니다. 전체 워크스페이스를 H2 문서로 보관하고 `revision`으로 오래된 쓰기를 409로 거절합니다. 이 범위는 개인용 개발 구성이며 인증·사용자별 문서는 추가해야 합니다.

기존 `/api/todos`의 데이터는 워크스페이스를 처음 생성할 때 한 번 이관합니다. 이후 UI는 `/api/workspace`만 사용합니다. 기존 `/api/todos`는 이전 스타터 호환용이며 신규 화면과 양방향 동기화하지 않습니다.

브라우저 데모는 `dotodo.workspace.v2`에 저장합니다. 기존 `dotodo.todos.v1`은 보존하며 새 형식이 없을 때 한 번 변환합니다. 서버 연결 실패 시 데모로 자동 전환하지 않습니다. 서로 다른 모드의 데이터는 자동 병합하지 않습니다.

다른 창의 변경은 자동 덮어쓰지 않습니다. 서버는 revision, 브라우저는 마지막으로 읽은 스냅샷 비교로 충돌을 표시합니다. 실시간 협업이나 WebSocket 동기화는 아닙니다. 브라우저의 거의 동시에 일어나는 경쟁 쓰기를 완전히 막는 분산 잠금은 구현하지 않았습니다.

## 실제로 구현하지 않은 서비스

TickTick의 유료·협업·외부 통합까지 완전히 같은 서비스는 아닙니다. 계정 로그인, 리스트 공유·초대·담당자, 외부 캘린더 구독, 파일 첨부, 이메일·음성 입력, AI 비서, 위치 알림, 앱스토어 서명·출시는 포함하지 않습니다.

웹 일정 알림은 사용자가 브라우저 권한을 허용하고 웹이 열린 동안만 표시합니다. 모바일 OS의 백그라운드 푸시는 구현하지 않았습니다. 타이머는 실제 종료 시각을 저장하고 다시 열 때 경과를 반영하며, 닫힌 앱이 OS에서 자동으로 코드를 실행하는 방식은 아닙니다.
